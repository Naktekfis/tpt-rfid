---
name: tpt-repo-safety
description: Check tpt-rfid constraints when work involves real student data, secrets, database destruction, deployment, authentication, or RFID hardware commands.
---

Read `.claude/knowledge/GATES.md` and the relevant hardware or platform reference before acting. Use synthetic data for tests. Do not print or commit secrets or real student records. Check whether the user has already authorized the specific action in this session; ask only if required authorization is still missing. Keep hardware commands within the documented safe command set unless the user explicitly authorizes otherwise.

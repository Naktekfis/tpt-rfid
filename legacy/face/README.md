# Archived face identification

Face engines, liveness, experimental CV routes, original kiosk and related UI/tests were moved here during the NFC transition (2026-10-23). The running app does not import or register them. Camera support remains active in `utils/camera.py` and `routes/camera_routes.py` for tool photography.

Existing database face embeddings, photos, legacy student RFID UIDs and downloaded model files are retained. Archived tests and scripts are historical references, outside the active test suite; their original app fixtures/paths may require restoration before use. No face-data deletion or conversion is part of this transition.
